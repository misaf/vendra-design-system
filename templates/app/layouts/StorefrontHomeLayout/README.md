# StorefrontHomeLayout

Home Atomic Design template with React-node slots for top/categories, featured designs, occasions, arrivals, weddings, journal and newsletter. It owns the main focus target, ordered section wrappers, static section labels, spacing and featured/wedding/newsletter bands. Optional sections receive externally controlled visibility flags.

StorefrontHomeCategories composes the top heading/category carousel from explicit props. StorefrontHomeFeatured composes featured cards and responsive view-all links. StorefrontHomeOccasions composes the occasion heading, description and carousel. StorefrontHomeStudio composes studio cards and explore-all navigation. StorefrontHomeWeddings composes the wedding-promotion text and links. StorefrontHomeJournal composes journal previews and read-journal navigation. The View retains section data/label/destination mapping and newsletter form/feedback. Home logic retains collection ordering, product identity/mapping, feature availability, newsletter validation/submission/persistence and focus. Shared logic retains navigation, locale, SEO and carousel behavior. The layout owns no data, state, effects or callbacks and does not choose feature availability.
