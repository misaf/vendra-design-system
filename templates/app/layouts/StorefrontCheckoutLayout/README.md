# StorefrontCheckoutLayout

Checkout Atomic Design template with React-node slots for notices, progress, heading, delivery review, payment, summary, bank status and success. The View controls payment visibility and conditionally constructs each slot. Notices stay outside the payment group so retry and persistence warnings remain available during bank/status transitions.

StorefrontCheckoutBank composes bank progress and PaymentStatus without adding a wrapper. StorefrontCheckoutProgress composes compact/wide progress for payment, bank and success; StorefrontCheckoutHeading composes the payment heading. View retains the payment-only progress spacing wrapper and navigation callbacks. StorefrontCheckoutNotices composes retry-review and recovery-storage notices outside payment visibility. StorefrontCheckoutSubmission composes WhatsApp handoff, processing/failure feedback and wide place/back actions. StorefrontCheckoutReceipt composes amount confirmation, payment card/Sheba and controlled receipt inputs. StorefrontCheckoutMethods composes method choices, unavailable feedback and wallet context from explicit controlled props. StorefrontCheckoutDeliveryReview composes delivery details/edit navigation from explicit labels, rows and callbacks. The layout owns the main focus target, payment columns, sticky summary and bank/success wrappers. The checkout View and logic retain all copy, payment-method state, receipt values, review/confirmation callbacks, persistence, gateway callbacks and order submission. The mobile submission action remains a separate Shell slot.
