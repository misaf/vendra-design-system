# StorefrontWeddingsLayout

Weddings Atomic Design template with React-node slots for heading, hero media, services, story, inquiry introduction, inquiry and feedback. It owns the main focus target, hero/services/story sections and responsive inquiry section, including its `inquiry` anchor. API feedback remains after the inquiry section.

StorefrontWeddingsHeading composes the heading and hero actions from explicit copy/action descriptors. The View retains localized mapping, WhatsApp availability, media, service cards, gallery/process content, inquiry fields and conditional form/success states, validation summary and API feedback. Weddings logic retains field state, date constraints, validation, submission payload, busy/error state, draft retention and focus. This layout owns no data, callbacks, persistence or browser effects.
