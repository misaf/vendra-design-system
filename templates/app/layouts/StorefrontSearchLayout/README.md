# StorefrontSearchLayout

Search Atomic Design template with React-node slots for heading, query field, close control, popular searches, results and empty-state feedback. It owns the main focus target, reading-width wrapper and responsive query/close row, preserving existing classes and slot order.

The View retains conditional content construction, localized heading mapping, SearchField, close navigation, popular-term controls, result rows/count/links and empty-state recovery. Search and shared site logic retain matching, URL/history updates, search reporting, return context, navigation and focus. This layout owns no data, callbacks, persistence or browser effects.

Verify query and language URL recovery, product exploration/back, close-to-origin context, clear/Escape and no-result recovery focus, popular searches, readable codes/prices, touch-width overflow, hydration and English/Persian responsive layouts.

StorefrontSearchHeading composes the display h1 from an explicit title without adding a wrapper. This layout retains heading placement.
