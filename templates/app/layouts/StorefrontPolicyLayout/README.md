# StorefrontPolicyLayout

Policy Atomic Design template with React-node slots for heading, policy navigation, notice, table of contents and document. It owns the main focus target, header, notice spacing, responsive policy columns and document wrapper.

StorefrontPolicyHeading composes the eyebrow, title, introduction and update metadata from explicit props. StorefrontPolicyNavigation composes labelled policy links from explicit props. StorefrontPolicyNotice composes the warning sample notice from explicit title/body props. StorefrontPolicyContents composes labelled section links and preserves sticky-panel classes. StorefrontPolicyDocument composes section headings, paragraphs and optional item lists from normalized descriptors. The View passes the layout directly and retains localized/document copy mapping, navigation/contents label mapping, nested list normalization, section descriptors and the empty Shell sticky-slot fragment. Policy logic retains document selection/fallback, section mapping and Persian numbering; shared logic retains policy link/current-state descriptors, routing, locale, SEO, focus and sticky measurements. The layout owns no data, state, effects or callbacks.

Preserve classes, landmarks, section anchors and focus targets. Verify switching policies, active links, direct/reloaded routes, section navigation, English/Persian accessibility, printing and responsive rendering.
