# StorefrontProductLayout

Product-page Atomic Design template with React-node slots for breadcrumbs, gallery, details, related designs and feedback. It preserves the main landmark, responsive product grid, gallery wrapper and sticky details panel.

StorefrontProductGallery composes gallery, fullscreen action and controlled lightbox from explicit props. StorefrontProductHeading composes code/copy action, category/badge, price/stock and description. StorefrontProductConfiguration composes controlled size/add-on groups. StorefrontProductPurchase composes the total/hint, controlled quantity, save and responsive add controls. StorefrontProductCare composes delivery text, the optional inquiry link and care/delivery accordion. StorefrontProductRecent composes the recently viewed heading, carousel and cards. StorefrontProductAdded composes the controlled bag-confirmation dialog. The product View supplies dialog data/callback mapping, recently viewed records/labels, visibility and its ErrorBoundary, delivery/care data mapping, purchase data/callback mapping, configuration data/callback mapping, heading data/callback mapping, gallery/lightbox data/state/callback mapping and toasts. Product logic retains configuration, totals, availability and purchase actions. StorefrontProductSticky composes the live total and add button in a separate Shell slot; View/logic supply its summary and action, while Shell retains responsive positioning, measurement and focus offsets. This layout has no store access, callbacks, persistence or browser effects.

Keep the existing classes and `main` focus target: shared responsive CSS and Shell's sticky/focus measurements rely on them. Verify product pricing, panel/content/code behavior, gallery/bag interactions, touch tablet shopping, phone rotation and hydration.
