# StorefrontPostLayout

Post Atomic Design template with React-node slots for feedback, article, actions, recommendations and related stories. It owns the main focus target, reading-width wrapper, article/actions wrappers and recommendation/related sections. `showArticle` is externally controlled visibility.

StorefrontPostLoading composes the loading h1, decorative Skeleton and localized status from explicit title/message props. StorefrontPostMissing composes level-one missing feedback and the localized journal recovery link from explicit title/backLabel/journalHref props. StorefrontPostHeading composes the journal back link, metadata, h1 and introduction from explicit props. StorefrontPostBlocks composes ordered paragraphs/headings/quotes/captioned images/tip lists from explicit records. StorefrontPostClassic composes the priority soft 4/3 image, paragraphs, quote and h2 from explicit props. StorefrontPostActions composes copy/shop controls from explicit labels, callback and href. StorefrontPostSocial composes the share/Instagram row from explicit labels/hrefs/showInstagram. The View retains visibility/copy/link/block/callback mapping, Instagram availability and list normalization, product cards and related-story cards. Post logic retains article selection, block/product/related mapping, localized metadata, share URLs, copy state and timer cleanup. Shared logic retains routing, locale, SEO and focus. The layout owns no data, state, effects or callbacks and does not choose the page state.

Preserve classes, article/section order and focus targets. Verify classic/block content, loading/missing recovery, copy feedback, back/shop/product/related links, social-link attributes, bilingual accessibility and responsive rendering.
