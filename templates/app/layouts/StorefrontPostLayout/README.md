# StorefrontPostLayout

Post Atomic Design template with React-node slots for feedback, article, actions, recommendations and related stories. It owns the main focus target, reading-width wrapper, article/actions wrappers and recommendation/related sections. `showArticle` is externally controlled visibility.

StorefrontPostLoading composes the loading h1, decorative Skeleton and localized status from explicit title/message props. StorefrontPostMissing composes level-one missing feedback and the localized journal recovery link from explicit title/backLabel/journalHref props. StorefrontPostHeading composes the journal back link, metadata, h1 and introduction from explicit props. StorefrontPostBlocks composes ordered paragraphs/headings/quotes/captioned images/tip lists from explicit records. The View retains visibility/copy/link/block mapping and list normalization, classic content, copy/shop actions, social links, product cards and related-story cards. Post logic retains article selection, block/product/related mapping, localized metadata, share URLs, copy state and timer cleanup. Shared logic retains routing, locale, SEO and focus. The layout owns no data, state, effects or callbacks and does not choose the page state.
