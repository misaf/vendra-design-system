# StorefrontContactLayout

Contact Atomic Design template with heading, details, form and feedback React-node slots. It owns the main focus target, header, responsive columns and detail/form wrappers. API feedback remains after the columns.

The View retains contact links, map/error boundary, directions, field controls, validation summaries, submission button, success/edit state and API feedback. Contact logic retains signed-in prefill, reply-channel validation, map fallback, submission, busy/error state and focus. This layout owns no data, callbacks, persistence or browser effects.
