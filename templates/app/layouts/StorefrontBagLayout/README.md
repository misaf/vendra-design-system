# StorefrontBagLayout

Bag/delivery Atomic Design template with React-node slots for notices, progress, heading, items/delivery fields, summary and empty state. The View supplies `showContents` to control the progress/heading/columns group. Notices and empty content remain outside that group so removing the final item can still expose Undo.

StorefrontBagItems composes editable LineItems and per-line stock warnings. StorefrontBagSummary composes summary rows, free-delivery progress, promo controls and navigation actions. The bag View supplies normalized line records, labels/formatter and visibility; it retains conditional slot construction, controls, copy, line quantity/removal/undo, delivery inputs, validation feedback, summary/promo descriptors and checkout callbacks. Bag logic retains persistence, stock limits, delivery rules and totals. StorefrontBagSticky composes the total and continuation controls in a separate Shell sticky slot; View supplies its total and action descriptors. This layout owns only the main landmark, column wrappers and sticky summary placement.
