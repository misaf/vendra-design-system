# StorefrontBagLayout

Bag/delivery Atomic Design template with React-node slots for notices, progress, heading, items/delivery fields, summary and empty state. The View supplies `showContents` to control the progress/heading/columns group. Notices and empty content remain outside that group so removing the final item can still expose Undo.

StorefrontBagDeliveryIntro composes the validation summary and guest sign-in prompt. StorefrontBagSender composes sender heading/hint and controlled name/phone fields. StorefrontBagCards composes per-item card messages/add controls and card-addition Undo feedback. StorefrontBagSchedule composes preparation/review feedback and controlled day/time choices. StorefrontBagLocation composes map/zone status, failed-map zone selection and address input inside the page-owned recipient section. StorefrontBagRecipient composes the recipient heading, saved-address chips and name/phone fields inside the page-owned delivery section. StorefrontBagProgress composes the compact/wide Steppers from explicit controlled props. StorefrontBagFeedback composes removal notices and empty recovery in separate slots outside conditional contents. StorefrontBagItems composes editable LineItems and per-line stock warnings. StorefrontBagSummary composes summary rows, free-delivery progress, promo controls and navigation actions. The bag View supplies normalized line records, labels/formatter and visibility; it retains conditional slot construction, controls, copy, line quantity/removal/undo, delivery inputs, validation feedback, summary/promo descriptors and checkout callbacks. Bag logic retains persistence, stock limits, delivery rules and totals. StorefrontBagSticky composes the total and continuation controls in a separate Shell sticky slot; View supplies its total and action descriptors. This layout owns only the main landmark, column wrappers and sticky summary placement.
