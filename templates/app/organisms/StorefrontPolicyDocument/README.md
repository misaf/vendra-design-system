# StorefrontPolicyDocument

Composes policy sections, numbered h2 headings, paragraphs and optional item lists from explicit normalized section descriptors. Preserves IDs, order, keyed fragments, copy classes, list visibility and scroll margins without adding a wrapper.

View retains section/paragraph/item list normalization and descriptor mapping. Policy logic retains document selection/fallback, localized content, Persian numbering and item availability. StorefrontPolicyLayout retains the document wrapper and responsive placement; shared logic retains routing, locale, SEO, focus and sticky measurements. This organism owns no state, calculations, persistence or browser effects.

Verify all five policies in English/Persian, paragraph/list content and visibility, section anchors, policy switching/reloads, touch/keyboard navigation, responsive containment, accessibility and screenshots against the previous version.
