# StorefrontTrackOrderActions

Composes tracking contact, repeat-order and lookup actions from explicit nullable contact and controlled repeat/lookup descriptors. Preserves the flex/wrap container, primary external contact link with message icon and rel/target, secondary repeat-order link with rotate icon and callback, and ghost lookup button with package-search icon. Adds no wrapper.

View retains order/contact visibility and localized descriptor mapping. Tracking/shared logic retain order-specific contact URL, repeat-order review/confirmation, bag changes and lookup reset/focus. Package Button and the shared router retain native activation/navigation semantics. This organism owns no state, rules, persistence or browser effects.

Verify bilingual destinations/labels, native link/button behavior, repeat-order review and cancellation without bag changes, confirmation, lookup reset/focus, wrapping and responsive markup against the previous version. Inspect external contact destinations without sending messages.
