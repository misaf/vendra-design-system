# StorefrontPolicyNotice

Composes the policy sample-content notice through the package warning Alert from explicit title/body props. Preserves alert semantics, copy and structure without adding a wrapper.

View retains localized copy mapping. StorefrontPolicyLayout retains notice placement and spacing. Policy/shared logic retain document selection, section mapping, numbering, routing, locale, SEO, focus and sticky measurements. Alert retains its warning presentation and accessibility. This organism owns no state, calculations, persistence or browser effects.
