# StorefrontSigninPolicies

Composes the phone-step policy note from explicit surrounding text and terms/privacy link descriptors. Preserves the paragraph/classes, text spacing and order, native links and underline classes without adding a wrapper.

View retains phone-step visibility and localized descriptor mapping. Sign-in/shared logic retains policy destinations; shared shell/router retains link interception, same-document navigation and history/focus behavior. No state, effects, browser APIs, routing or policy rules belong here.

Verify bilingual wording/order/spacing, accessible link names and hrefs, native keyboard/touch activation, same-document policy navigation and history return. Compare initial/validation/returned states, responsive rotation, desktop/TV, containment and accessibility against the previous version.
