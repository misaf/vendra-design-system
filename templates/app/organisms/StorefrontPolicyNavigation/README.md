# StorefrontPolicyNavigation

Composes the labelled policy navigation, list and links from explicit label/links props. Preserves link order, keyed fragments, hrefs, aria-current, wrapping and classes without adding a wrapper.

View retains localized label mapping and list normalization. Shared navigation logic retains link descriptors/current state, routing, locale, SEO and focus; policy logic retains document selection, section mapping and Persian numbering. StorefrontPolicyLayout retains slot placement. This organism owns no state, calculations, persistence or browser effects.
