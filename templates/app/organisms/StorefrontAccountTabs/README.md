# StorefrontAccountTabs

Composes controlled account tabs from explicit items/value/change/label and selected-panel children. Preserves pill variant, scrolling list classes, panel class and child placement. Adds no wrapper.

View retains panel visibility and descriptor mapping. Account/shared logic retains feature eligibility, allowed-tab selection/fallback, routing and state. Package Tabs retains selection, RTL keyboard navigation, roving focus and tab/panel ARIA relationships; shared TV navigation retains edge handoff. No state, effects, browser APIs or account rules belong here.

Verify bilingual selected-tab/panel links, single tab stop, Home/End and mirrored arrows, TV edge handoff, direct tab routes, all panel branches, draft continuity, responsive touch/rotation, overflow and accessibility against the previous version.
