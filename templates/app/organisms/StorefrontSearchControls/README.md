# StorefrontSearchControls

Composes the controlled SearchField and secondary close link from explicit query (label, placeholder, value, onChange) and close (label, href) descriptors. Preserves the vf-q focus target and existing responsive row/input wrappers, classes and control order.

View retains localized descriptor mapping. Search/shared logic retain matching, URL/history updates, reporting, return context, navigation and focus. Package SearchField/IconButton retain input, clear/Escape and link semantics. StorefrontSearchLayout places the controls slot. This organism owns no state, calculations, persistence or browser effects.

Verify bilingual typing and query recovery, popular terms, clear/Escape and empty recovery focus, product exploration/back, close-to-origin context, delivery details, touch-width containment and responsive markup against the previous version.
