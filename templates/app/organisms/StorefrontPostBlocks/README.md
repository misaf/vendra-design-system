# StorefrontPostBlocks

Composes ordered article paragraphs, h2 headings, quotes, captioned Pictures and tip lists from explicit block records. Preserves keyed fragments, conditional block rendering, image sizes/alt/captions, classes and sibling structure without adding a wrapper.

View retains block visibility, explicit descriptor mapping and outer/tip-list normalization. Post logic retains article selection, localized body mapping, block flags, image resolution and captions. StorefrontPostLayout retains article placement/spacing; shared logic retains routing, locale, SEO and focus. This organism owns no state, calculations, persistence or browser effects.

Verify every block type and order, bilingual source copy, heading hierarchy, image alt/caption/sizes, tip lists, normal/classic/loading/missing visibility, touch/keyboard article navigation, history/reload, tablet rotation, responsive containment, accessibility and screenshots against the previous version.
