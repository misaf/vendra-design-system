# StorefrontPostProducts

Composes the article product recommendation grid from explicit product records. Preserves ordered keyed soft-frame ProductCards with name/price/stock/images/href props and the existing responsive two/three-column wrapper, gap and top margin, including an empty grid.

View retains product-list normalization. Post logic retains article product selection/order, fixed product-code names, localized price/stock/image descriptors and product URLs. StorefrontPostLayout retains recommendation section placement and article visibility; ProductCard retains image, stock and link presentation. This organism owns no state, calculations, persistence or browser effects.
