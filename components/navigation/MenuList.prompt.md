Vertical <nav> of NavLinks with an optional eyebrow — mobile menu (variant="menu") or footer columns (variant="footer").
```jsx
<MenuList title="Shop"><NavLink variant="footer">Bouquets</NavLink><NavLink variant="footer">Boxes</NavLink></MenuList>
```

## Usage
**Use when:** Vertical lists of links: account menu, mobile drawer, footer columns.

**Don’t use when:** Don’t use for actions with side effects (Button) or tabbed content (Tabs).
