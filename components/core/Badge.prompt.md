Small uppercase status label on product media or rows ("New", "Seasonal", "Sold out").
```jsx
<Badge tone="sage">Seasonal</Badge>
```
Tones: neutral, accent (gold), sage, ochre, plum, danger, solid (ink). Uppercase is dropped in Persian.

## Usage
**Use when:** Short status on an item: New, Sold out, Paused, “in 2 days”.

**Don’t use when:** Don’t use for clickable filters (Tag) or messages longer than three words.
