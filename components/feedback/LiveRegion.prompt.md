**LiveRegion** — one per page, mounted at load (a region created at the same moment as its text is often not read). Update its text for screen changes ("Shop — 24 designs"), bag updates and filter results. `politeness="assertive"` only for failures.

## Usage
**Use when:** Announcing non-visual changes to screen readers: bag count, filter results.

**Don’t use when:** Don’t use for content already visible and focused, or duplicate Toast announcements.
