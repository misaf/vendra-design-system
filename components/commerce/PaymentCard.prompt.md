Card-to-card transfer panel (Iranian bank transfer). Groups the number in 4s (LTR, tabular), copy button flips to "Copied" for 2s.
```jsx
<PaymentCard cardNumber="6037991234567890" holder="Vendra Florist" bank="Melli" amount="4,600,000 Toman" labels={{copy:'Copy',copied:'Copied'}} />
```

## Usage
**Use when:** Card-to-card payment instructions after checkout.

**Don’t use when:** Don’t use to collect card details — it only displays them.
