# @vendra/design-system

React components, design tokens, bilingual (English/Persian, right-to-left) styles and per-tenant
themes for Vendra florist storefronts.

```sh
npm install @vendra/design-system react react-dom react-aria-components @internationalized/date
```

React 18.2+, `react-aria-components` 1.21+ and `@internationalized/date` 3.12+ are peer
dependencies, so your app and the components share one React Aria copy.

```jsx
import '@vendra/design-system/styles.css';
import {VendraProvider, Button} from '@vendra/design-system';
import {tenantCss} from '@vendra/design-system/theme';
```

| Import | What it is |
|---|---|
| `@vendra/design-system` | The components (with `VendraProvider`) plus `format`, `dates`, `commerce`, `maps` and `ICON_SVGS`. |
| `@vendra/design-system/styles.css` | Fonts, tokens, base styles and every `ag-*` class. |
| `@vendra/design-system/theme` | `tenantCss`, `validate`, `checks`, `tokens`, `designTokens`, `email` and the default spec. |
| `@vendra/design-system/tenants/<slug>.css` | The sample tenant themes. |
| `@vendra/design-system/tokens.json` | Every design token as W3C design tokens (DTCG JSON). |

Full documentation, tenant themes and the reference storefront:
[github.com/misaf/vendra-design-system](https://github.com/misaf/vendra-design-system).

This folder is the package's source; `dist/` is generated by `npm --prefix apps/storefront run build`
at the repository root. Never edit `dist/`.
