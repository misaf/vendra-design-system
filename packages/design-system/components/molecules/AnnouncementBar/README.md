# AnnouncementBar

Slim inverse banner above the header. Centered text, optional dismiss.

```jsx
<AnnouncementBar label="Announcement" onClose={hide} closeLabel="Dismiss">
  Order by 18:00 for same-day delivery in Karaj
</AnnouncementBar>
```

## Usage

**Use when:** One site-wide message above the header: free delivery, holiday cutoffs.

**Don’t use when:** Don’t use for errors, personal messages, or more than one at a time.
