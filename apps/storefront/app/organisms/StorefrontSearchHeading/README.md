# StorefrontSearchHeading

Composes the search-page heading from an explicit title prop, preserving the h1 and ag-display class without adding a wrapper.

View retains localized prop mapping. Search/shared logic retain matching, query and language URL/history state, search reporting, navigation and focus. StorefrontSearchLayout retains heading placement. This organism owns no state, calculations, persistence or browser effects.

Verify one localized page h1 across popular, results and empty states, query recovery and English/Persian responsive markup against the previous version.
