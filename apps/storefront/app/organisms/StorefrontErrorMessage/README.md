# StorefrontErrorMessage

Composes server-error messaging through the package EmptyState from explicit eyebrow/title/accent/body props. Preserves the flower icon, localized 500 code, level-one heading, accent and body without adding a wrapper.

View retains localized copy mapping and recovery controls. Error logic retains reload behavior and bidi-isolated phone wording; shared logic retains routing, locale, SEO and focus. StorefrontErrorLayout retains message/actions placement and the main focus target. This organism owns no state, data selection, persistence or browser effects. The lazy-page load-failure boundary remains a separate shared recovery mechanism.
