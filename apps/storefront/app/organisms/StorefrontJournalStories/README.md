# StorefrontJournalStories

Composes ordered journal BlogCards from explicit stories. Preserves keyed fragments, stacked layout, soft frames, 4/3 aspect and story props without adding a wrapper.

View retains list normalization. Journal logic retains filtering, pagination slices, story mapping, localized metadata, image resolution and article hrefs. StorefrontJournalLayout retains the responsive grid wrapper/placement; BlogCard retains presentation and link/image semantics. This organism owns no state, calculations, persistence or browser effects.

Verify first/later-page card order and content in English/Persian, lazy images, category/search/empty/loading states, reloads, touch/keyboard article navigation, responsive containment, accessibility and screenshots against the previous version.
