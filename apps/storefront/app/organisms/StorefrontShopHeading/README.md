# StorefrontShopHeading

Composes the localized shop heading through SectionHeader from explicit eyebrow/title/accent props. Preserves the level-one heading and accent without adding a wrapper.

View retains copy mapping. Shop logic retains category/filter/sort/pagination state, URLs and product selection; shared logic retains routing, locale, SEO and focus. StorefrontShopLayout retains heading placement. This organism owns no state, persistence, business rules or browser effects.
