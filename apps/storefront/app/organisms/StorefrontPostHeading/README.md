# StorefrontPostHeading

Composes the article journal back link, metadata, h1 and introduction from explicit journalHref/backLabel/meta/title/intro props. Preserves the native link and arrow icon, existing classes and sibling structure without adding a wrapper.

View retains localized copy/link mapping. Post logic retains article selection, metadata formatting and block/classic content mapping; StorefrontPostLayout retains article visibility, placement and spacing. Shared routing and page logic retain navigation, locale, SEO and heading focus. This organism owns no state, calculations, persistence or browser effects.
