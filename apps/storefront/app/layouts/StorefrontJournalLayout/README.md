# StorefrontJournalLayout

Journal Atomic Design template with React-node slots for heading, search, feedback, featured story, stories and pagination. It owns the main focus target, header/search wrappers and responsive article grid.

StorefrontJournalHeading composes the title and category controls from explicit props. StorefrontJournalSearch composes the controlled search field from explicit props. StorefrontJournalEmpty composes no-result feedback and recovery. StorefrontJournalLoading composes the decorative skeleton and localized status. StorefrontJournalFeatured composes the wide arch featured BlogCard from explicit props. StorefrontJournalStories composes ordered story cards inside the layout-owned grid. StorefrontJournalPagination composes explicit paging props. The View passes the layout and conditional featured story directly, retaining the multi-child feedback and empty sticky fragments. The View retains visibility, localized/story/value/callback/paging mapping, category/story list normalization and focus scrolling. Journal logic retains category/query state, matching, page clamping, first-page resets, URL navigation, story mapping and localized metadata. Shared page logic retains locale, SEO and focus. This layout owns no data, state, effects, callbacks or visibility rules.
