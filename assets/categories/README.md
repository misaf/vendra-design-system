# Demo category photography

Twelve distinct images generated with OpenAI's built-in image generation on 18 October 2026 for this fictional florist storefront. They illustrate category types and do not represent actual stock. The original generated files remain outside the repository; the site uses responsive 240×240 and 640×640 WebP exports. Product photos remain separate. Category labels provide the accessible names, so the card photos are decorative.

The prompt set is saved in [prompts.json](prompts.json). Each subject was generated as a separate image using the shared studio-photography prompt. The first three prompts used equivalent wording: “Create ONE photorealistic studio photograph”, “Composition: square 1:1”, “no important content near corners” and “Distinct new photograph”.
